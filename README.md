# First HTML Project

A beginner-friendly HTML project demonstrating the use of heading elements (`<h1>` through `<h4>`) to structure a book-like document with chapters, sections, and diagrams.

## What You'll Learn

- How to use HTML heading tags (`<h1>`, `<h2>`, `<h3>`, `<h4>`)
- Document hierarchy and structure
- Semantic HTML formatting

## How to Run

1. Clone this repository
2. Open `index.html` in your browser
